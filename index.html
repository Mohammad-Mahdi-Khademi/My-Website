01.A

Vision–language models
Human–robot interaction

Ongoing · since May 2026

“Pick that up.
Give it to them.”

Turning a spoken request into an object handover with the RoArm M3 Pro.

I’m developing a framework that combines voice input with a vision–language model (VLM). The goal is for the arm to understand the request, locate the intended object, work out how to grasp it, and deliver it to a specified person.

The interaction is speaker-aware: who is speaking, what they are referring to, and who should receive the object all matter. I’m implementing and evaluating this connection between language, visual understanding, and physical action.

  2. 02Locate
  3. 03Grasp
  4. 04Deliver

Intended workflow · RoArm M3 Pro, 5+1 DOF

01.B

Reinforcement learning
Parallel parking

Ongoing investigation

Where does learning
improve a classical model?

Parallel parking as a test case for classical control, hybrid approaches, and pure reinforcement learning.

I’m investigating how RL can improve model-based parking, and when a learned policy should handle the maneuver directly. The comparison is between a classical approach, a hybrid that combines the model with RL, and pure RL execution.

A

Classical

A model defines the maneuver.

B

Hybrid

RL improves a model-based approach.

C

Pure RL

A learned policy executes the maneuver.

Work this builds on / March 2024–May 2026

I developed a deep RL framework for tangent-based parallel parking, validated it in Webots, and deployed the learned policy on an NVIDIA JetRacer using ultrasonic perception.
